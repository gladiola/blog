# Demo Programs
Listed below are some selected programs from the repo, by language or system.

### [JPO_02APR2018A](https://github.com/gladiola/blackmagic/tree/Demo/ASP.NETCore2.0/JPO_02APR2018A)
Selected files from an ASP.NET Core 2.0 program. References to Microsoft tutorials and reference docs are included in the source code.

Program features include:  QR code two factor authentication with Microsoft Authenticator, logins with Twitter and Facebook, requiring and redirecting to HTTPS, and the use of UserSecrets in development.

### [SystemCheck.ps1](https://github.com/gladiola/blackmagic/blob/Demo/PowerShell/CPSC5700_Benchmarking/SystemCheck.ps1)
Lists details about:  computer manufacturer, model, processor, BIOS, operating sytem, and current processes

### [greenXterm.sh](https://github.com/gladiola/blackmagic/blob/Demo/FreeBSD/greenXterm.sh)
Simple shell script to make green and black terminal windows in X11.

### [portListC.sh](https://github.com/gladiola/blackmagic/blob/Demo/FreeBSD/portListC.sh)
Shell program to install packages. Having shell scripts like these was a helpful part of standing up a poudriere jail.
